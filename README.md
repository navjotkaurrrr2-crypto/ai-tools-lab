# ai-tools-lab

## Project Description

AI Tools Lab is a Python project that contains sorting algorithms and utility functions. It is designed to help practice Python programming concepts and basic problem-solving.

## Installation

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone <repository-url>

## Usage

You can use the utility functions in your Python programs.

Example:

```python
from utils import add

result = add(10, 20)
print(result)

### Sorting Example

The sorting function can be used to arrange numbers in ascending order.

```python
numbers = [5, 2, 8, 1, 3]
numbers.sort()

print(numbers)
